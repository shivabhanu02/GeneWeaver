# GeneWeaver — Day 10 GPU Benchmark

**Date:** 18 November 2026  
**Hardware:** NVIDIA Tesla T4  
**CUDA Version:** 13.0  

## Objective

Compare the execution performance of the Python CPU Smith-Waterman
implementation with the CUDA GPU implementation.

## Benchmark Workload

| Parameter | Value |
|---|---:|
| Candidate sequences | 256 |
| Reference sequence length | 128 bp |
| Candidate sequence length | 128 bp |
| Total DP cells | 4,194,304 |
| Match score | +2 |
| Mismatch penalty | -1 |
| Gap penalty | -2 |

## Initial Benchmark Results

| Implementation | Execution Time |
|---|---:|
| CPU | 1,561.636 ms |
| GPU | 8.444 ms |
| Speedup | 184.94x |

## Correctness Verification

The alignment scores generated by the CPU and GPU implementations
were compared for all 256 candidate sequences.

**Result: PASSED — All CPU and GPU scores matched exactly.**

## Observations

- CUDA batch processing successfully processed 256 candidates.
- GPU execution was significantly faster for this benchmark workload.
- The CUDA kernel generated a grid-size warning indicating possible
  GPU underutilization, but execution completed successfully.
- GPU timings include the benchmark's allocation and data-transfer
  operations.
- Results represent a pure Python CPU baseline compared with the
  CUDA implementation on an NVIDIA Tesla T4.
