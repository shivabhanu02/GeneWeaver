# GeneWeaver
## GPU-Accelerated CRISPR Alignment Engine

GeneWeaver is a bioinformatics project focused on developing an efficient DNA sequence alignment engine using CPU processing and NVIDIA GPU acceleration.

### Project Objectives
- Parse DNA sequences in FASTA format.
- Validate DNA sequences.
- Implement CPU-based sequence alignment.
- Develop GPU-accelerated alignment using Numba CUDA.
- Support sequence processing and benchmarking.
- Compare CPU and GPU performance.

### Technology Stack
- Python
- BioPython
- NumPy
- Numba CUDA
- Dask
- Textual
- Pytest

### Project Structure
- data/: Input datasets
- src/: Source code
- tests/: Unit tests
- benchmarks/: Performance benchmarks
- docs/: Project documentation
- reports/: Progress and evaluation reports
